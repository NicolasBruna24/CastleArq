```

```

Exit code 2 is pytest's *collection/interrupt* code, not the exit code 1 of a
failing test run — the signature of a suite that aborts before running tests.
This matches the defect already established and reproduced in B9.57.2/B9.57.3:
`app/version.py:6` imports `tomllib` unconditionally, and `tomllib` entered the
standard library in **Python 3.11**. On CPython 3.10 the suite aborts during
collection with `ModuleNotFoundError: No module named 'tomllib'` and **zero
tests execute**.

Evidence available for this run: job conclusion, failing step name, exit code,
and the check-run annotation. The job log body is not retrievable from this
environment (the log endpoint returns HTTP 403 "Must have admin rights"), so
the exact traceback of *this* run is UNKNOWN. No code was changed to investigate.

This 3.10 failure is **not** related to B9.57.6 and is not merged with it: it
predates the fix, is version-caused, and concerns a different module.
