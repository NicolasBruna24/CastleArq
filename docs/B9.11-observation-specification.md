# B9.11: OBSERVATION / CONTEXT ACQUISITION SPECIFICATION

## Independent Environment Observation Layer

### 1. Purpose

Block B9.11 establishes an independent, pure domain and probe subsystem for acquiring **verifiable facts from the local environment**.

Architectural hierarchy:
$$\text{OBSERVATION (B9.11)} \longrightarrow \text{KNOWLEDGE} \longrightarrow \text{EVALUATION} \longrightarrow \text{DECISION} \longrightarrow \text{EXECUTION}$$

B9.11 belongs **strictly** to Observation / Context Acquisition.
It represents **what an environment source observed**, not what the system concludes about compatibility or authorization.

---

### 3. Epistemic States: `ObservationState`

Ratified Decision **D-11.1**:
```python
class ObservationState(str, Enum):
    OBSERVED = "observed"
    UNAVAILABLE = "unavailable"
    ERROR = "error"
```

- **`OBSERVED`**: The fact was successfully acquired from the source.
- **`UNAVAILABLE`**: The required source or interface does not exist (e.g. `lspci` is not installed, `/etc/os-release` is missing).
- **`ERROR`**: The source was attempted, but failed (e.g. process timeout, crash, permission error).

#### Critical Distinctions:
$$\text{UNAVAILABLE} \neq \text{UNSUPPORTED}$$
$$\text{ERROR} \neq \text{UNSUPPORTED}$$
$$\text{UNKNOWN} \neq \text{FALSE}$$

### 4. Domain Contracts

Located in [`app/observation_domain.py`](file:///home/brunapc/LocalAI%20Hub/app/observation_domain.py). All objects are `@dataclass(frozen=True)` and all collections are `tuple`.

#### A. `ObservedValue`
Atomic fact container with state, raw value, provenance source identifier, and optional technical details.
```python
@dataclass(frozen=True)
class ObservedValue:
    state: ObservationState
    value: Any = None
    source: str = ""
    detail: str | None = None
```

#### B. `PlatformObservation`
Captures operating system family, kernel release, machine architecture, and Linux distribution ID.

#### C. `DeviceObservation` & `HardwareObservation`
Captures memory from `/proc/meminfo` and discrete display controllers from `lspci -nn` without synthetic vendor name mapping. System RAM is never copied into a fabricated `cpu` device; `devices == ()` when no structured device evidence exists. `HardwareObservation.acquisition_error: ObservedValue | None` is `None` on success and explicitly `UNAVAILABLE` (missing `lspci` binary) or `ERROR` (non-zero exit / timeout / `OSError`) otherwise.

#### D. `RuntimeObservation`
Captures facts about installed runtime executables (strictly `llama.cpp` and `ollama`):
- `canonical_id`: "llama.cpp" or "ollama"
- `executable_path`: Full path to binary
- `raw_version`: Exact version string from `--version` (`UNAVAILABLE` when the binary produces no output; `ERROR` on non-zero exit / timeout / `OSError`)
- `detected_backends`: Tuple of explicit backend strings per `detect_backend_evidence` (`--<backend>` flag, `backend(s): ...` enumeration, or `built with <backend>`; incidental prose is NOT evidence).

#### E. `EnvironmentContext`
Top-level snapshot binding the captured platform, hardware, runtimes, and snapshot timestamp.

### 5. Separation of Pure Parsers and Effectful Probes

Located in [`app/observation_probe.py`](file:///home/brunapc/LocalAI%20Hub/app/observation_probe.py).

#### A. Pure Parsers (Zero I/O)
- [`parse_os_release(text)`](file:///home/brunapc/LocalAI%20Hub/app/observation_probe.py#L58): Parses `/etc/os-release` lines into key-value pairs without file access.
- [`parse_meminfo(text)`](file:///home/brunapc/LocalAI%20Hub/app/observation_probe.py#L77): Returns `ParseMemResult` distinguishing `absent` (no `MemTotal` line), `bad_number` (numeric field absent/unparseable/negative) and `bad_unit` (unit missing or not an explicit `kb`/`b`/`mb` spelling). A bare number never implies bytes.
- [`parse_lspci_nn(text)`](file:///home/brunapc/LocalAI%20Hub/app/observation_probe.py#L110): Extracts device descriptions, 4-digit hex vendor IDs, and 4-digit hex device IDs verbatim.
- [`detect_backend_evidence(help_text)`](file:///home/brunapc/LocalAI%20Hub/app/observation_probe.py#L62): Pure backend-evidence predicate for `llama.cpp --help`. A backend (`vulkan`/`cuda`/`sycl`) counts ONLY as (1) CLI flag `--<backend>`, (2) backend enumeration `backend(s): ... <backend>`, or (3) build declaration `built|build|compiled with ... <backend>` (case-insensitive, whole-word). Incidental prose (e.g. "cuda cores", "vulkan-like") is NOT evidence; nothing is inferred.

#### B. Absence vs Error Contract
- `platform.system()` / `platform.release()` / `platform.machine()` returning empty/whitespace -> `UNAVAILABLE` with `value=None` (never the artificial string `"unknown"`).
- `/proc/meminfo` / `/etc/os-release` / `lspci` / runtime binaries missing -> `UNAVAILABLE` (`HardwareObservation.acquisition_error` records the missing `lspci` binary explicitly).
- `lspci` / `--version` / `--help` non-zero exit, timeout, or `OSError` while executing -> `ERROR` via `ObservedValue(detail=...)` or `HardwareObservation.acquisition_error` (never `pass`, never `UNSUPPORTED`).
- System RAM (`memory_total_bytes`) is never duplicated as a synthetic `cpu` `DeviceObservation`; `devices` holds only structured `lspci -nn` evidence.

#### B. Effectful Prober with Injected I/O (D-11.3)
`EnvironmentObserver` accepts injected callables:
- `command_runner: CommandRunner`: Runs commands with strict timeouts (no `shell=True`).
- `file_reader: FileReader`: Reads file contents safely.
- `which_finder: WhichFinder`: Resolves binary paths.
- `timestamp_provider: TimestampProvider`: Generates deterministic timestamps for testing (D-11.4).

### 6. No-Inference Guarantees

B9.11 enforces strict non-inference rules:
1. **No Vendor Fabrication**: PCI vendor `8086` is stored as `"8086"`, not transformed into `"Intel"`.
2. **No Backend Assumption**: The presence of a runtime binary does **not** imply CPU or Vulkan support. A backend is recorded ONLY on explicit syntactic evidence in `--help` (CLI flag `--<backend>`, `backend(s): ...` enumeration, or `built with <backend>`); incidental prose is NOT evidence.
3. **No Hardware Compatibility Linking**: The presence of an Intel or NVIDIA GPU does **not** imply that Vulkan or CUDA is functional.
4. **No Error-to-Unsupported Mapping**: If `lspci` is missing it is `UNAVAILABLE` (`acquisition_error`); if it exits non-zero, times out, or raises `OSError` it is `ERROR` (`acquisition_error`). Devices are never marked `UNSUPPORTED`, and failures are never hidden with `pass`.

---

### 7. What B9.11 Does NOT Do

B9.11 explicitly does **not**:
- Evaluate compatibility or generate `CompatibilityResult`.
- Produce `EvaluationDecision` (`ALLOW` / `DENY` / `ESCALATE`).
- Recommend or select backends or runtimes.
- Execute user prompts or inference models.
- Repair, install, or download software.
- Touch or replace legacy `app/hardware.py` or `app/runtimes.py`.
- Wire into production execution services.
